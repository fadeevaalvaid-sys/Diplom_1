# Задание 1: Юнит-тесты

## Автотесты для проверки программы, которая помогает заказать бургер в Stellar Burgers

### Реализованные сценарии

Созданы юнит-тесты для проверки класса `Burger`.

Проверяются методы:
- `set_buns` - установка булочек;
- `add_ingredient` - добавление ингредиента;
- `remove_ingredient` - удаление ингредиента;
- `move_ingredient` - перемещение ингредиента;
- `get_price` - расчёт стоимости бургера;
- `get_receipt` - формирование чека.

Для изоляции тестируемого класса используются моки (`Mock`).

Процент покрытия класса `Burger` — **100%**.

### Структура проекта

- `praktikum` - пакет, содержащий код программы;
- `tests` - пакет, содержащий юнит-тесты;
- `tests/test_burger.py` - тесты класса `Burger`.

### Запуск автотестов

**Запуск тестов и проверка покрытия:**

```bash
python -m pip install -r requirements.txt
python -m pytest tests/test_burger.py --cov=praktikum.burger --cov-report=term-missing
```
